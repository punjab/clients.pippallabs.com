# Domain docs

This is a single-context repository.

Before changing the application, read:

- `CONTEXT.md` for canonical business language and invariants.
- Relevant records in `docs/adr/` for accepted architecture decisions.
- The numbered product specifications at the repository root for product contracts.

Use canonical terms from `CONTEXT.md` in code, tests, issues, and UI copy. Surface any conflict with an accepted ADR rather than silently overriding it.
